# Starter assets

Geometric placeholder sprites generated deterministically by a throwaway
node script (same minimal-PNG technique as `tools/gen-starter-assets.mjs`).
They exist so the template runs on first load; replace them with Asset Forge
generations or imports before any serious playtest.

Keys (see `config.demo.json` → `assets.sprites`):

- `player.png`, `shot.png`, `foe-shot.png`, `pickup.png`
- `enemy-grunt.png`, `enemy-skitter.png`, `enemy-stinger.png`
